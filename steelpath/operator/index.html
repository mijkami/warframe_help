    Opérateur

    Focus

    • Unairu permet de te rendre insensible à certains contrôles (Poise, premier talent) et de te rez en Tenno (Last Gasp)
    • Vazarin peut te rendre invincible (Protective Sling)
    • Zenurik pour la regen energie si besoin (trouver d'autres sources au plus vite)
    • Madurai utile pour les dégats d'opérateur plus tard dans le jeu (boost dégâts tenno + bonus puissance/vitesse cast pour frame)

    Survie

    L'opérateur peut participer à la survie de la warframe :

    • résurrection autonome :
      • via le talent Last Gasp de l'école de Focus Unairu
      • permet de faire revenir la warframe à la vie en tuant 3 ennemis en opérateur sur 15 secondes
      • disponible pour toutes les branches d'opérateur : débloquer les passifs liés à la voie concernés pour y accéder en permanence (monter rang max). D'autres passifs déliés permettent d'augmenter les dégats & la survie de l'opérateur facilitant la résurrection.
      • les compétences actives de Madurai facilitent les kills en opérateur pour le rez
      • le glaive (Phahd, attaque secondaire) de l'amplificateur facilite le rez
    • protection préventive :
      • via le talent de l'arbre Vazarin Protective Sling
      • permet de rendre invulnérables les cibles alliées (votre warframe comprise) pour 5s après avoir "dash" à travers
      • utiliser Magus Cloud pour faciliter l'opération
      • gameplay très particulier /répétitif & nécessite le Tektolyst débloqué pour les lvl cap (ennemis lvl 9999)
    • contrôle des ennemis :
      • via l'arcane d'opếrateur Magus Lockdown
      • un dash opérateur permet de créer une mine (max 2) qui bloque jusqu'à 10 ennemis chacune pour 4 secondes sur 15 mètres

    Amplificateurs

    On décrit les amplificateurs par le numéro de la partie du Prism, Scaffold (Support) et Brace (Atelle), exemple 111 = Raplak Pencha Clapkra. Amplis "meta" :

    Code Nom des Parties Utilité Usage
    123 Raplak Shraksun Lohrin débuter (juste la reput Certus) débutant
    177 Raplak Propa Certus mono-cible / lancer un AoE pour les Vomvalysts pref Eidolons
    147 Raplak Phahd Certus mono-cible / lancer un glaive pour se rez pref Cascade
    547 Cantic Phahd Certus mono-cible (multishot) / lancer un glaive pref Cascade
    747 Klamora Phahd Certus multi-cible / lancer un glaive SteelPath comfort + OK Cascade

    Arcanes

    Ce sera surtout l'opérateur qui devra parfois être adapté au contenu.

    • opérateur :
      • cascade : Magus Cloud + autre (ex : Magus Lockdown)
      • perturbation : Magus Lockdown + autre
      • autres :
        • Magus Melt : +dmg pour Anges Zariman + rez opérateur
        • Magus Anomaly : attire les ennemis, pratique pour certaines mise à prix/bounties (Deimos)
        • Emergence Dissipate : regen énergie
    • ampli :
      • 1er slot obligatoire : Eternal Eradicate
      • 2nd slot au choix :
        • Eternal Onslaught
        • Virtuous Strike
        • Virtuous Shadow
        • Eternal Logistics

    Artefacts Tektolyst / Tauron

    Les artefacts tektolyst sont des "armes ultimes" pour opérateurs :

    • donnent accès à des nouveaux mods et arcanes s'appliquant aux armes d'opérateurs :
      • gros boost de dégats, rend "viables" toutes les écoles d'opérateur en lvl cap (ennemis lvl 9999). Sans Tektolyst, Madurai "obligatoire" pour de la Cascade cap.
      • arcanes impactant les armes de frames (boost feu sur les armes secondaires)
      • buffs et attaques ultimes intéressants mais trop aléatoires / peu utilisés en l'état
    • accessibles après avoir fini la quête The Old Peace, en drop dans le mode de jeu Rebellion Perita et la boutique de Marie

    Modding Tektolyst généraliste

    • Mods :
      • Ubri-Kaneph : dégats de base
      • Omni-Evi : crit chance / crit damage
      • Hok-Kaal : protection contrôle en opérateur
      • Hayan-Dabor : multishot
      • Vikla-Safor : Fire Rate + Ammo Efficiency
    • Arcane : Zid-An Uskos : Kills en opérateur donnent un buff permanent jusqu'à +250% dégats feu sur arme secondaire (de warframe)
