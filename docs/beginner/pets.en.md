

# Companions

## First Companions


![Taxon](../assets/beginner/Taxon.webp){ width="100" align=right }

- Robotic: [Taxon](https://wiki.warframe.com/w/Taxon)
    - **acquisition**: complete the Earth-Venus junction
    - ??? note "build"
    
            - early: some shields or armor / health, max [Vacuum](https://wiki.warframe.com/w/Vacuum) urgently
            - mid-game: add [Guardian]() + max [Molecular Conversion](https://wiki.warframe.com/w/Molecular_Conversion), add [Manifold Bond](https://wiki.warframe.com/w/Manifold_Bond) (Cetus rank 3)

![Kubrow](../assets/beginner/400px-HurasKubrow.webp){ width="114" align=right }

- Animal: Kubrow
    - **acquisition**: complete the Venus-Mercury junction then the quest [Howl of the Kubrow](https://wiki.warframe.com/w/Howl_of_the_Kubrow) (to quickly get an egg to incubate, do runs on [Mantle, Earth](https://wiki.warframe.com/w/Mantle) and break nests)
    - ??? note "build"
        
            - early: some shields or armor / health, max [Fetch](https://wiki.warframe.com/w/Fetch) urgently
            - mid-game: depends on the sub-type of [kubrow](https://wiki.warframe.com/w/Kubrow#Types) you randomly obtain


No need to invest too much into them, but don't neglect them either.
From the start of the game they provide almost essential utility via mods to obtain / max urgently:

- **loot vacuum**: [Vacuum](https://wiki.warframe.com/w/Vacuum) / [Fetch](https://wiki.warframe.com/w/Fetch)
- **loot doubler**: [retriever mods](https://wiki.warframe.com/w/Category:Retriever_Mods) on animal companions
- enemy / object radar: [Animal Instinct](https://wiki.warframe.com/w/Animal_Instinct)

Add mods with a few points for survival (armor/health or even shields) so they can continue to fulfill their utility role.

## Mid-game Companions
Later in the game you can get other useful companions.
Among them, two stand out for new players:

- [Smeeta Kavat](https://wiki.warframe.com/w/Kavat#Smeeta) which gives a 300% XP buff via its mod [Charm](https://wiki.warframe.com/w/Charm).
    - ??? note "Acquisition"
        - upgrade your Incubator with [the Kavat Upgrade Segment](https://wiki.warframe.com/w/Orbiter_Segments#Kavat_Incubator_Upgrade_Segment) (blueprint in the Dojo in Tenno Lab or drop in Grineer missions). Requires an [Argon Crystal](https://wiki.warframe.com/w/Argon_Crystal) that drops only in the [Void](https://wiki.warframe.com/w/Argon_Crystal) and 60,000 Alloy Plates, see [Resources](../farm/resources.md) for good spots
        - Genetic codes will be a limiting factor.
        - The best place to scan kavats to get them is the 2nd stage of the [Inaros quest](https://wiki.warframe.com/w/Sands_of_Inaros) doable only once
        - other farming location: Formido on Deimos (Sabotage)
        - plan for control that doesn't deal damage and immobilizes (Ivara's arrow, Equinox's night mode 2)
        - if possible use the [Synthesis Scanner](https://wiki.warframe.com/w/Synthesis_Scanner) with speed and double scan upgrades (can double drops in this case). Stack [loot boosters](../farm/resources.md/#boosters) if possible
        - By default a 1 in 2 chance of getting a Smeeta, otherwise you'll get an [Adarza](https://wiki.warframe.com/w/Adarza_Kavat) oriented towards crits. You can obtain 2 [Genetic Code Templates](https://wiki.warframe.com/w/Genetic_Code_Template) from another player (trade or sale) to guarantee Smeeta but this is not necessary at all
- [Panzer Vulpaphyla](https://wiki.warframe.com/w/Panzer_Vulpaphyla) which helps avoid death and inflicts viral in area (damage bonus). Very very useful.
    - **acquisition**: see **[Steelpath companions section](../steelpath/pets.md)**
