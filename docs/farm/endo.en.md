# Endo

Used to level up [mods](../mods/index.md).

## **Beginner**
- **dissolve duplicate mods**. There is even an interface for that, keep about ten duplicates per mod just in case before knowing their value better.
- do **[Maroo's weekly mission](https://wiki.warframe.com/w/Maroo#Weekly_Mission)** on Mars for [Ayatan statues](https://wiki.warframe.com/w/Ayatan_Treasures)

!!! note "Details"
    
    - requires having completed quest [Stolen Dreams](https://wiki.warframe.com/w/Stolen_Dreams) after Phobos junction
    - think about repairing Ayatan statues with Ayatan stars to increase their Endo value: we add Ayatan stars found in missions in crates, via the mod fusion interface at the top right
    - give back fused Ayatan statues to Maroo to get max Endo per statue
